# Power BI for Data Analytics: Course Portfolio

This repository contains my practical assignments and portfolio projects completed as part of the **"Power BI for Data Analytics"** course by [Luke Barousse](https://www.youtube.com/@LukeBarousse). 

Through this course, I developed hands-on experience in building end-to-end analytical solutions, from data extraction and modeling to advanced DAX calculations and interactive dashboard design using real-world data science job postings.

---

## 📂 Featured Projects

### 1. [Project 1: Data Jobs Overview Dashboard](./_Project_1/README.md)
An exploratory dashboard providing clear insights into job availability, salary trends, and top data professions in 2024. It features a main high-level market view and a detailed drill-through page for specific job titles.
* **Key Skills Applied:** Data Transformation (Power Query), DAX & Measures (Median salaries, Job counts), Interactive Reporting (Drill-Through navigation, Slicers), and visual KPIs with integrated sparklines and trendlines.

### 2. [Project 2: Data Job Market Analysis: Remote vs. On-Site Dynamics](./_Project_2/README.md)
An advanced interactive dashboard engineered to examine the data career landscape with a focus on work flexibility. It assesses how workplace format affects compensation benchmarks, global geographic distribution, and technology stack demand.
* **Key Skills Applied:** DAX Field Parameters for ad-hoc exploration, Cross-page Slicer Synchronization, Star Schema Data Modeling, and Parameterized Power Query Paths.

---

## 🛠️ Core Competencies Developed

* **Data Preparation (ETL):** Cleaning, shaping, and transforming raw data using **Power Query (M Language)**.
* **Data Modeling:** Designing robust relational models (**Star Schema**) with fact and dimension tables.
* **DAX (Data Analysis Expressions):** Creating custom measures, KPIs, and utilizing advanced features like Field Parameters for dynamic visuals.
* **Data Visualization & UX:** Building interactive, user-friendly reports in **Power BI Desktop** using buttons, drill-throughs, synchronized slicers, and custom layouts.
